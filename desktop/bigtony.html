☁ Run Omni Gateway + Data Brain on Fly.io

So your agents work from your phone or any PC without your computer on. Needs a Fly.io account with billing. Files in your repo: omni/fly.toml, omni/Dockerfile, databrain/fly.toml, databrain/Dockerfile.

1. Install flyctl: https://fly.io/docs/flyctl/install/
2. fly auth login
3. Gateway:  cd omni
   fly launch --copy-config --no-deploy   (pick a unique app name)
   fly secrets set OPENROUTER_API_KEY=sk-or-... OMNI_GATEWAY_TOKEN=pick-a-password
   fly deploy
4. Data Brain:  cd databrain
   fly launch --copy-config --no-deploy
   fly deploy
5. Key Broker: Gateway URL = https://YOUR-GATEWAY.fly.dev, Token = your OMNI_GATEWAY_TOKEN
   Data Brain URL = https://YOUR-DATABRAIN.fly.dev
Keys live only as Fly secrets, never in files.
